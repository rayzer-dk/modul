CodeCart PRO Theme 8.7.7 — установка, обновление и удаление

ПЕРЕД НАЧАЛОМ
Перед началом установки или обновления обязательно создайте полную резервную копию файлов сайта и базы данных.

УСТАНОВКА
1. В админке откройте Расширения → Установка расширений.
2. Загрузите Theme_CodeCart_Pro_v8.7.7.ocmod.zip.
3. Откройте Расширения → Модификаторы и нажмите Обновить.
4. Очистите кеш Twig и кеш темы.
5. Откройте Расширения → Расширения → Темы и установите CodeCart PRO Theme.
6. После установки тема выключена. Проверьте настройки, затем вручную включите статус и сохраните.
7. В Система → Настройки → Магазин выберите CodeCart PRO как активную тему, если это требуется вашей конфигурацией.

ОБНОВЛЕНИЕ
1. Создайте полный backup файлов и базы данных.
2. Загрузите новый архив поверх установленной версии через установщик расширений.
3. Обновите модификаторы.
4. Очистите кеш Twig и темы.
5. Откройте настройки темы, проверьте версию 8.7.7 и сохраните настройки.
6. Проверьте главную, категорию, товар, корзину, checkout, блог и мобильную версию.

УДАЛЕНИЕ
1. При необходимости экспортируйте настройки и создайте backup.
2. В настройках выберите, сохранять ли пользовательские таблицы при удалении.
3. Удалите тему в списке расширений.
4. Удалите установочный пакет/модификатор штатными средствами OpenCart.
5. Обновите модификаторы и очистите кеш.
6. Проверьте, что активной выбрана другая установленная тема.

ПРИМЕЧАНИЕ
По умолчанию таблицы заявок, блога и расширенных отзывов сохраняются, чтобы исключить случайную потерю данных. Их удаление выполняется только при заранее отключенной настройке сохранения данных.

При обновлении существующие настройки, включая пользовательские CSS и JavaScript, сохраняются. После установки откройте основные настройки и включите «Информационный режим», если сайт должен работать без продаж.

Аварийное восстановление после Parse error в featured_product.php

Если предыдущая версия уже создала ошибочный файл storage/modification/catalog/controller/extension/module/featured_product.php:
1. В админке удалите старый модификатор с кодом codecart_pro_theme или его дубликаты.
2. Установите Theme_CodeCart_Pro_v8.7.7.ocmod.zip.
3. Обязательно обновите модификаторы.
4. Очистите кеш Twig и кеш модификаторов.

Если витрина остаётся недоступной до обновления модификаторов, временно удалите только сгенерированный файл storage/modification/catalog/controller/extension/module/featured_product.php. Не удаляйте исходный catalog/controller/extension/module/featured_product.php. После этого сразу обновите модификаторы, чтобы OpenCart заново создал безопасную копию.

ОБНОВЛЕНИЕ ДО 8.7.7
1. Удалите старую запись модификатора CodeCart PRO Theme с кодом codecart_pro_theme, если есть дубликаты.
2. Установите архив 8.7.7 и обновите модификаторы.
3. Откройте настройки темы один раз: это зарегистрирует безопасные Events совместимости и выполнит миграцию блога.
4. Сохраните настройки и очистите кеш Twig/темы.
