# Азбука приключений

Интерактивное приложение для обучения русскому чтению и начальному счёту детей 7–10 лет. Статус: тестовая версия 0.4.0, не финальный релиз.

Реализовано локально: 87 уроков чтения, 51 урок математики, 20 рассказов, 12 мини-игр, карта шести миров, индивидуальный прогресс и ежедневный учебный маршрут из пяти заданий. Базовый курс работает без сервера приложений; установочная PWA-сборка требует HTTPS.

Ветка `Модуль` изолирована от `main`. Полный архив исходников и аудио передан в чате, но пока НЕ загружен в GitHub: этот каталог содержит документацию, а не рабочую сборку. Не публикуйте его как развёрнутое приложение до загрузки файлов проекта.

Перед публичным релизом требуются проверка установки PWA на Android и iOS, контроль качества русской офлайн-озвучки и педагогическое тестирование с детьми.
